## The problem

A small company's work lives in eight different places, and only the founder carries the context. Every AI tool knows one department; none of them knows the company. A single refund decision needs the customer, the order, the stock, the policy and the money, all together.

A typical morning without Lodos.md is **43 notifications**. With it, it's **3 decisions**: approve the refund, send the supplier order, start the ad budget. The team handles the rest.

## Three things, together

Running a company end to end takes three things. Each exists on its own in the market; all three together don't.

- **A brain that knows the company**: decisions, policies, customers, orders, history. Versioned line by line; the founder can read and correct it.
- **Hands that work in real systems**: refunds, stock sync, customer replies, publishing, pull requests. Every action is verified at the source and reversible.
- **Governance that knows who can do what**: which AI, on which account, doing which job, with how much autonomy. Critical steps wait for approval; everything is logged.

## Lodos Brain

Memory is a wiki: pages and links the founder can read and edit, instead of a hidden summary. Every note has a date and context, every conversation teaches it, and stale information is set apart from current facts. Instructions hidden in outside content can't write into it. It lives on your device and works with any model. Models change; the brain stays.

## One app, eight tools, one brain

- **Integrations**: Shopify, Amazon and 129 systems where agents actually do the work
- **Vault**: an encrypted vault like 1Password; the AI uses a key without ever seeing its value
- **Chat**: a group chat with your cofounder AI and the agent team
- **Kanban**: tasks the agents pick up, closed through GitHub
- **Calendar**: a full calendar plus publishing to 20+ social platforms
- **Wiki**: where Lodos Brain lives, linked like Obsidian and self-updating
- **Workflows**: automation like Zapier or n8n, set up by describing it in chat
- **Engage**: WhatsApp, Instagram and Gmail in one inbox, answered by an AI that knows the order

## You set the autonomy

Each agent has a level (observer, preparer, executor, autonomous), and each kind of action (reading, replying to customers, publishing, money, deleting) can be off, ask first, or run without asking. Three things are never left to the AI: granting permissions, raising its own autonomy, and declaring a job "done".

## Not even we can see it

Your keys stay with you. You see the secret; the AI sees only its name (`{{secrets.stripe.key}}`); Lodos.md sees encrypted bytes. It's local-first, cloud backup is optional and end-to-end encrypted, and there is zero telemetry. 175 security rules are checked on every build. If one breaks, the release doesn't ship. Every action goes into a signed log, so tampering is detected.

Teams get the same model: Signal-style end-to-end encryption per member, and an agent can never see what its member can't.
